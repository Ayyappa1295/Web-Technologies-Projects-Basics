# 🌐 Chrome New Tab Clone

A simple and interactive **Google Chrome New Tab Page Clone** built using HTML5, CSS3, and JavaScript. This project recreates the look and feel of a Chrome-style homepage with a Google-inspired search bar, website shortcuts, a live clock, and customizable appearance settings.

## 📌 Project Overview

The Chrome New Tab Clone is a frontend web development project designed to practice the fundamentals of HTML, CSS, and JavaScript.

It provides a clean homepage where users can search Google, access their favorite websites, add or remove shortcuts, switch between light and dark modes, and customize the background color.

## ✨ Features

- **Google-Inspired Homepage:** Colorful Google-style logo and a clean layout.
- **Google Search:** Search the web directly using the search bar.
- **Live Clock and Date:** Displays the current date and time.
- **Website Shortcuts:** Quick access to YouTube, Gmail, GitHub, Instagram, and Google.
- **Add Shortcuts:** Add custom website names and URLs.
- **Remove Shortcuts:** Delete unwanted website shortcuts.
- **Dark Mode:** Switch between light and dark themes.
- **Background Customization:** Choose from white, blue, pink, green, and yellow backgrounds.
- **Local Storage:** Saves shortcuts, theme preferences, and background settings in the browser.
- **Responsive Design:** Adapts the layout for desktop and mobile screens.
- **Customize Panel:** Manage appearance settings from a dedicated panel.

## 🛠️ Technologies Used

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Google Chrome or another modern web browser.
4. Use the search bar, website shortcuts, and customization options.

No additional installation or build tools are required.

## 💻 How to Use

### 1. Search Google
Enter a search query in the search bar and press Enter or click the search icon.

### 2. Open Website Shortcuts
Click any shortcut icon to open the corresponding website in a new tab.

### 3. Add a Shortcut
Click **Add shortcut**, enter a website name, and provide its URL.

### 4. Remove a Shortcut
Hover over a shortcut and click the `×` button.

### 5. Enable Dark Mode
Click **Customize Chrome** and select **Toggle dark mode**.

### 6. Change the Background
Open the customization panel and select your preferred background color.

### 7. Reset Appearance
Click **Reset appearance** to restore the default white background and light theme.

## ⚠️ Limitations

- This is a frontend practice project, not an official Google Chrome application.
- It does not replace Chrome's actual New Tab page.
- Google search requires an internet connection.
- Saved shortcuts and preferences are stored locally in the browser.
- Local Storage data may be lost if browser data is cleared.
- The project does not include a backend or user authentication.
